# Dino Attack 正式训练奖励设计

**日期：** 2026-08-30  
**阶段：** 阶段 8 / `TASK-8.11`  
**状态：** 对话设计已批准，等待用户复核本文后并入既有实施计划

## 1. 目标

奖励首先要求 Agent 获胜，其次在获胜策略之间偏好更高的最终肉余额，并以很小的战斗事件奖励帮助早期探索。奖励不得通过重复事件、伤害刷取、部署成本重复计费或失败时囤积肉产生捷径。

本设计改变正式 Dino Attack 训练的奖励数值和 `gamma`，不改变 Human 模式、战斗伤害、房屋返肉、50 秒自然失败、五区部署、4D 动作或五流结构化观测协议。

## 2. 终局奖励

自然终止进入 `Ending` 时，只结算一次终局奖励：

```text
胜利：+10 + 0.01 * final_meat
失败：-1
```

其中：

- 胜负必须读取 `RoundManager.PlayerWon`，不得通过剩余恐龙数量推断。
- `final_meat` 是胜利结算时 `DinoSpawner.ResourcesToSpend` 的最终余额，包含房屋死亡返还的肉。
- 肉奖励只在胜利时发放；失败不发肉奖励。
- 肉奖励不做 `clip`，也不设置人工最大值。环境的资源来源和部署成本自然决定实际范围。
- 必须在胜利清除恐龙、场景 reload 或其他清理操作影响状态之前读取并冻结 `final_meat`。
- 50 秒超时和恐龙全部死亡均为自然失败，结算 `-1`；基础设施 `truncated` 不结算胜负或肉奖励。

该语义优化的是“胜利时最终肉余额最大”，因此房屋返肉既是玩法资源，也计入终局效率；它不等价于只最小化累计部署成本。

## 3. 过程奖励

仅在 `Running` 且 episode 尚未结算时发放：

| 事件 | 奖励 | 去重规则 |
|---|---:|---|
| 消灭一名守卫（地面或墙上） | `+0.02` | 每个守卫最多一次 |
| 摧毁一面墙 | `+0.05` | 每面墙最多一次 |
| 非法部署 | `-0.02` | 每次被正式部署服务拒绝的非 Wait 动作一次 |
| 合法 `Wait` | `0` | 不访问位置、不产生部署副作用 |

守卫和墙的奖励必须依赖既有死亡事件及稳定身份去重，不能按伤害次数、动画事件或重复禁用回调发放。

当前正式布局为最多 8 名守卫和 3 面活动墙，全部过程正奖励最多为：

```text
8 * 0.02 + 3 * 0.05 = 0.31
```

因此即使完成全部过程目标后失败，在没有非法动作时总回报仍不高于 `-0.69`，不能通过过程奖励把失败变成正回报。

## 4. 明确不使用的奖励

- 房屋摧毁不直接加奖励；它已经通过返还 `100` 肉影响胜利终局奖励。
- 合法部署不再按恐龙成本即时扣奖励；成本已反映在最终肉余额中，重复扣除会双重计费。
- 不使用逐决策或逐秒时间惩罚。
- 不按伤害量、距离目标、移动距离、区域选择或目标切换发放奖励。
- 恐龙死亡不额外惩罚；其部署成本已经减少最终肉余额。
- 胜利清理剩余恐龙时不得触发返肉、死亡惩罚或其他奖励。

## 5. 折扣与算法一致性

正式 Dino Attack 的 PPO、FPO、ReinFlow 和 PolicyFlow 统一使用：

```yaml
gamma: 0.995
```

在最多约 80 次决策的一局中，最晚终局奖励回传到最早决策时约保留 `0.995^79 = 67.3%`。这会轻微偏好更早获胜，但比历史 3DBall 的 `gamma=0.99` 更完整地保留胜负和肉奖励的长期信用。

`gamma` 属于正式 Dino Attack 实验协议和 checkpoint/config metadata。所有正式算法比较必须使用相同值；历史 3DBall 配置和结果保持不变。

## 6. 结算顺序

自然终止采用以下顺序：

1. `RoundManager` 冻结真实 `PlayerWon`。
2. Agent 停止接受新的动作和过程奖励。
3. 若胜利，读取一次 `final_meat`。
4. 加入一次终局奖励并调用 `EndEpisode()`。
5. TerminalSteps 可被训练器读取后，再执行胜利清场和完整场景 reload。

基础设施中断只调用 `EpisodeInterrupted()`；若进程异常且没有最终 observation，仍按并行训练规格丢弃不完整 episode 片段，不伪造终局奖励。

## 7. 必要验证

仅保留以下聚焦验证：

- 胜利分别以 `0`、`100` 和包含房屋返还的肉余额结束，终局奖励严格等于 `10`、`11` 和对应线性值，且只发一次。
- 50 秒失败和恐龙全灭均结算 `-1`，即使仍有肉也不发肉奖励。
- 基础设施 interrupted 不发胜负或肉奖励。
- 同一守卫或墙的重复死亡/禁用通知不会重复奖励。
- 非法部署为 `-0.02`，合法 `Wait` 为 `0`，合法部署没有额外成本惩罚。
- 胜利清场不会产生额外奖励；四种正式算法配置均为 `gamma=0.995`。

不为本奖励修改恢复已删除的全量 Unity suite、Player build、100-episode 正式评估或长训练。

## 8. 取代关系

本设计取代当前 `DinoTrainingAgent` 的 `WinReward=10`、`LossPenalty=10`、`DefenderKillReward=0.25`、`WallDestroyedReward=0.5`、`InvalidActionPenalty=0.05`、`PlacementCostPenalty=0.1` 和 `TimePenaltyPerDecision=0.0005` 正式训练语义。

结构化观测/4D 动作规格及并行训练规格中“奖励来源不变”的条款由本文取代；其他观察、动作、终止、场景和并行采样约束继续有效。
